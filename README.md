# Biohub – Cell Tracking During Development: 4th place solution

Training and inference code for our 4th-place solution (public 0.969 / private 0.962) in the Kaggle competition
[Biohub – Cell Tracking During Development](https://www.kaggle.com/competitions/biohub-cell-tracking-during-development).

**Pipeline:** 3D Net detectors → learned linking (LightGBM edge model) → a learned division prior inside the ILP →
fork verification and gap bridging.

The code is being cleaned up and will be released here soon.
